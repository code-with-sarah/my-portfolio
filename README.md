## 🚀 Features & Sections
- **Responsive Navigation Bar:** Built using Bootstrap 5 navbar component.
- **Hero Section:** Personal introduction and quick call-to-action buttons.
- **About Me:** Professional summary and background details.
- **Education:** Academic history and course details.
- **Technical Skills:** Displayed using interactive cards and badges.
- **Featured Projects:** Showcases top machine learning and NLP projects.
- **Contact Form & Info:** Form interface and direct contact details.

## 🛠️ Technologies Used
- **HTML5**
- **Bootstrap 5** (Official CDN & Bootstrap Icons)
- **Custom CSS**
- **Git & GitHub**
- **Vercel** (Deployment)

## 📌 How to Run Locally
1. Clone or download this repository.
